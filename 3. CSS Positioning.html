Position Property

CSS Position Property

Static positioning: The element stays in the normal document flow. Top, bottom, left, and right properties do not affect it.

Relative positioning: The element stays in the normal document flow, but it can be moved relative to its original position using top, bottom, left, or right.

Absolute positioning: The element is removed from the normal document flow and positioned relative to its nearest positioned ancestor.

Fixed positioning: The element is removed from the normal document flow and positioned relative to the viewport. It stays in the same place when the page is scrolled.

Sticky positioning: The element behaves like a relatively positioned element until a specified scroll position is reached, then it sticks to that position.
